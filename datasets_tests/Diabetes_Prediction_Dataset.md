# Diabetes Prediction Dataset

### About the Dataset

This dataset contains demographic and health-related information about individuals. The goal is to **predict whether a person has diabetes or not**.

### Columns

| Column | Description |
|---|---|
| **gender** | Person's gender. |
| **age** | Person's age in years. |
| **hypertension** | Whether the person has hypertension. `0 = No`, `1 = Yes`. |
| **heart_disease** | Whether the person has heart disease. `0 = No`, `1 = Yes`. |
| **smoking_history** | Person's smoking history. |
| **bmi** | Body Mass Index. |
| **HbA1c_level** | HbA1c blood measurement. |
| **blood_glucose_level** | Blood glucose level. |
| **diabetes** 🎯 | Target variable. `0 = No`, `1 = Yes`. |

### 🎯 Target

**`diabetes`** → the value the model should predict.
