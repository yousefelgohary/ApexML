# Penguins Dataset

### About the Dataset

This dataset contains information about penguins, including their physical measurements, location, sex, and observation year.

### Columns

| Column | Description |
|---|---|
| **island** | Island where the penguin was observed. |
| **bill_length_mm** | Length of the penguin's bill in millimeters. |
| **bill_depth_mm** | Depth of the penguin's bill in millimeters. |
| **flipper_length_mm** | Length of the penguin's flipper in millimeters. |
| **body_mass_g** | Penguin body mass in grams. |
| **sex** | Penguin's sex: male or female. |
| **year** | Year when the observation was recorded. |

### Dataset Use

The dataset can be used to **discover groups of similar penguins based on their characteristics**.
